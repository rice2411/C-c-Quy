# Common UI List

Thư mục `components/ui` dùng gom các primitive UI (button, input) để thay thế lặp class Tailwind và giữ dark mode, focus ring thống nhất.

## Danh sách component nên refactor (ưu tiên gợi ý)

| Thứ tự | Component đích        | Mô tả ngắn                                                             | Nơi đang lặp / tham chiếu                                                                                                                                                                           |
| ------ | --------------------- | ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1      | `Button`              | Nút primary, secondary, ghost, danger; hỗ trợ `disabled`, `type`, icon | `components/ConfirmModal.tsx`, `pages/Storage/ingredient/IngredientForm.tsx`, `pages/Settings/index.tsx`, nhiều `pages/*`                                                                           |
| 2      | `Input`               | Text input một dòng, kích thước, `error`, `disabled`                   | `pages/Storage/ingredient/IngredientForm.tsx`, `pages/Storage/product/ProductForm.tsx`, `pages/Orders/components/OrderFiltersToolbar.tsx`, `pages/Orders/components/modals/CreateCustomerModal.tsx` |
| 3      | `Select`              | `<select>` styled thống nhất                                           | `pages/Users/components/UserFilters.tsx`, `pages/Storage/ingredient/IngredientForm.tsx`, `pages/Storage/product/ProductForm.tsx`                                                                    |
| 4      | `Textarea`            | Nhiều dòng, giống token với `Input`                                    | `pages/Storage/product/ProductForm.tsx`                                                                                                                                                             |
| 5      | `Label`               | Typography label form (`block text-sm font-medium`)                    | `pages/Orders/components/modals/OrderFiltersModal.tsx`, `pages/Storage/product/ProductForm.tsx`, `components/AutocompleteInput.tsx`                                                                 |
| 6      | `Field` / `FormField` | Bọc `Label` + control + hint/error                                     | Các form lớn: Storage, Orders, Customers                                                                                                                                                            |
| 7      | `IconButton`          | Nút vuông hoặc tròn chỉ icon (đóng modal, xóa dòng)                    | `components/BaseModal.tsx`, bảng ingredient                                                                                                                                                         |
| 8      | `Checkbox` / `Switch` | Hàng filter có pattern `label + flex gap-2`                            | `pages/Orders/components/modals/OrderFiltersModal.tsx`                                                                                                                                              |
| 9      | `Badge` / `Chip`      | Tag chọn hoặc bỏ chọn (màu theo palette)                               | `pages/Storage/product/ProductForm.tsx`                                                                                                                                                             |
| 10     | `Spinner`             | Trạng thái loading inline                                              | Form, `components/AutocompleteInput.tsx`                                                                                                                                                            |
| 11     | `Card`                | Khối nền + bo góc cho list mobile và desktop                           | `SupplierCard`, `CustomerCard`                                                                                                                                                                      |
| 12     | `Tabs` / `TabList`    | Tab header có thể thay pattern hiện tại                                | `pages/Storage/TabsHeader.tsx`                                                                                                                                                                      |
| 13     | `Typography`          | Chuẩn hóa `p`, `span`, heading (`h1..h6`)                              | `pages/Login/index.tsx`, dashboard/list pages                                                                                                                                                       |
| 14     | `Avatar` / `Image`    | Chuẩn hóa `img` (fallback, size, rounded)                              | account/customer/supplier cards                                                                                                                                                                     |
| 15     | `LinkText`            | Chuẩn hóa `a` có style/focus nhất quán                                 | pages có external/internal links                                                                                                                                                                    |
| 16     | `List` primitives     | Chuẩn hóa `ul`, `ol`, `li`                                             | list sections, settings/help screens                                                                                                                                                                |
| 17     | `Table` primitives    | Chuẩn hóa `table`, `thead`, `tbody`, `tr`, `td`, `th`                  | desktop tables: orders/customers/users/suppliers                                                                                                                                                    |

## Đã có sẵn (cân nhắc giữ nguyên hoặc bọc lại)

- `components/BaseModal.tsx`, `components/BaseSlidePanel.tsx`, `components/ConfirmModal.tsx` (footer có thể dùng `Button` variants).
- `components/AutocompleteInput.tsx` (có thể dùng `Input` bên trong để đồng bộ style).
